AI Form Summarizer — local demo

This is a stand-in "form" for exercising the real webhook (POST /api/webhook) without needing an actual Google Forms/Typeform integration yet. Start the backend (npm run dev), then open http://localhost:3000/demo/ (served by the backend itself, not opened as a local file — that avoids a same-origin/CORS detour entirely). Fill in a couple of fields and submit — you'll see exactly what the backend returns, including the honest "no AI provider configured" error if you haven't set an API key yet.
